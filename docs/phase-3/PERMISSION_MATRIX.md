# Phase 3 Permission Matrix

| Role | Permissions |
|---|---|
| SUPER_ADMIN | all |
| ADMIN | USER_READ, USER_MANAGE, ROLE_MANAGE, CONTENT_READ, CONTENT_CREATE, CONTENT_EDIT, CONTENT_REVIEW, CONTENT_PUBLISH, MEDIA_MANAGE, ENTITLEMENT_ADJUST, DEVICE_RESET, AUDIT_READ, ANALYTICS_READ, SUPPORT_MANAGE |
| CONTENT_EDITOR | CONTENT_READ, CONTENT_CREATE, CONTENT_EDIT, MEDIA_MANAGE |
| MODERATOR | CONTENT_READ, CONTENT_REVIEW |
| TEACHER_REVIEWER | CONTENT_READ, CONTENT_REVIEW |
| SUPPORT_AGENT | USER_READ, SUPPORT_MANAGE, DEVICE_RESET, CONTENT_READ |
| ANALYST | CONTENT_READ, ANALYTICS_READ |

Backend must enforce these permissions. UI visibility is only a usability layer.
